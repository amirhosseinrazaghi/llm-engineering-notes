# 🧠 LLM Engineering Notes

یادداشت‌های ساختاریافته‌ی Obsidian از دوره‌ی مهندسی هوش مصنوعی — مفاهیم، مسیر توسعه‌ی پروژه، و اشتباهات واقعی، همه مستند و به‌هم لینک‌شده.

> از صفر تا ساخت یه چت‌بات واقعی — همراه با هر مفهومی که یاد گرفتم و هر اشتباهی که ازش درس گرفتم.

---

## 📖 این چیه؟

این یه **وُلت کامل Obsidian**‌ه (نه فقط چندتا فایل مستقل)، که موقع گذروندن دوره‌ی [اسم دوره رو اینجا بذار] از کانال [اسم کانال رو اینجا بذار] نوشتمش. هر مفهومی که یاد گرفتم، هر پیشرفتی که تو پروژه‌ام داشتم، و هر باگی که باهاش دست‌وپنجه نرم کردم، اینجا با جزئیات و به زبان ساده مستند شده.

اگه داری همین دوره رو می‌بینی یا می‌خوای مهندسی هوش مصنوعی یاد بگیری، امیدوارم این یادداشت‌ها کمکت کنن.

🎥 لینک دوره: [https://youtu.be/OyKf29aTepc?si=NhXQ2oQ_MrUS5LQh]
📺 کانال یوتیوب: [neonlearn@]

---

## ⚠️ نکته خیلی مهم قبل از استفاده

**این فایل‌ها فقط تو Obsidian کامل کار می‌کنن، نه تو یه ادیتور متن ساده یا حتی خودِ گیت‌هاب.**

اگه فایل‌ها رو مستقیم تو گیت‌هاب باز کنی، این‌ها رو می‌بینی:
- لینک‌های `[[این‌شکلی]]` به‌جای اینکه کلیک‌پذیر باشن، فقط متن خام نشون داده می‌شن.
- فایل `.canvas` (نقشه‌ی بصری پروژه) به‌جای یه نمودار قشنگ، یه تیکه کد JSON خام نشون داده می‌شه.

برای اینکه همه‌چیز درست کار کنه (لینک‌ها، تگ‌ها، نقشه‌ی گراف، Canvas)، باید طبق راهنمای پایین، کل پوشه رو به‌عنوان یه **وُلت** تو Obsidian باز کنی.

## 🚀 چطور ایمپورت کنم؟ (قدم‌به‌قدم)

### قدم ۱: نصب Obsidian
اگه هنوز نصب نکردی، از سایت رسمی و رایگانش دانلود کن: **[obsidian.md](https://obsidian.md)**

### قدم ۲: دانلود این ریپازیتوری
بالای همین صفحه، دکمه‌ی سبز **Code** رو بزن → **Download ZIP** رو انتخاب کن → فایل زیپ رو تو یه پوشه‌ی دلخواه اکسترکت (extract) کن.

(اگه با Git راحتی، می‌تونی به‌جاش این دستور رو بزنی:)
```
git clone https://github.com/amirhosseinrazaghi/llm-engineering-notes.git
```

### قدم ۳: باز کردن به‌عنوان وُلت
Obsidian رو باز کن، از صفحه‌ی اصلی (Vault switcher) گزینه‌ی **"Open folder as vault"** رو بزن، و همون پوشه‌ای که اکسترکت کردی رو انتخاب کن.

### قدم ۴: لذت ببر
حالا همه‌چیز باید درست کار کنه:
- روی لینک‌های آبی‌رنگ کلیک کن تا بین یادداشت‌ها جابه‌جا بشی.
- از نوار کناری، **Graph view** رو باز کن تا نقشه‌ی کل یادداشت‌ها رو ببینی.
- فایل `.canvas` رو دوبار کلیک کن تا نقشه‌ی بصری کامل پروژه باز بشه.
